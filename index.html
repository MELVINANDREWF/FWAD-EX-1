Overview

TCP/IP is a layered set of protocols developed in the 1970s for ARPANET by Vint Cerf and Bob Kahn. It defines how data is addressed, split into packets, transmitted, routed and received. Each layer does one job and relies on the layer below, so layers can be improved independently.
